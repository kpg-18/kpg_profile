# Kruparth Prakash Gowda — Portfolio

A static portfolio site for GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy with GitHub Pages

Push this folder to a GitHub repository, then enable **Settings > Pages > Deploy from a branch** and select the `main` branch.

Project repository links can be added to the arrow controls in `index.html` once they are available.
